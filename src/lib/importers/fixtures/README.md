# Testdateien für den Schematic-Import

Echte Dateien aus offenen Projekten, unverändert übernommen:

| Datei | Herkunft | Lizenz |
|---|---|---|
| `worldedit-v3.schem` | [PrismarineJS/prismarine-schematic](https://github.com/PrismarineJS/prismarine-schematic) (`test/schematics/`) | MIT |
| `monument.mcstructure` | [microsoft/minecraft-samples](https://github.com/microsoft/minecraft-samples) (`custom_features/example_feature_set`) | MIT |

Für `.litematic` und `.nbt` liegen keine frei weitergebbaren echten Dateien im Repo.
Diese Formate wurden von Hand mit den Testdateien von
[litemapy](https://github.com/SmylerMC/litemapy) (GPL-3.0, u. a. Regionen mit negativer
Größe) und mit Vanilla-Strukturen geprüft.
